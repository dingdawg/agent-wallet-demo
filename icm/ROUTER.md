# Public ICM router

This is the public ICM entry point for the DingDawg Agent Wallet demo. It makes
the demo easy for an MCP client to understand without disclosing private MiLA
or DingDawg implementation.

| Need | Load |
|---|---|
| Understand the demo boundary | `010-public-contract/CONTEXT.md` |
| Validate the public contract | `010-public-contract/done.sh`, then `verify.sh` |

This is a local demonstration of policy outcomes. It does not create a real
wallet, transmit a transaction, hold funds, sign for a customer, or settle a
payment.
